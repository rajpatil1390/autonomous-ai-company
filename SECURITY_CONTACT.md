# Security Contact

Do not report vulnerabilities through public issues, discussions, pull
requests, operational channels, or screenshots.

## Preferred private channel

Use the repository's **Security → Report a vulnerability** function to open a
private GitHub Security Advisory. Include:

- affected version and component;
- impact and realistic threat model;
- minimal reproduction using synthetic data;
- proposed mitigation, if known; and
- whether disclosure is time-sensitive.

If private advisories are unavailable, contact the maintainers through the
private security contact configured by the repository owner. This repository
does not publish a fabricated email address or credential.

## Handling expectations

Acknowledgement is targeted within one business day and initial assessment
within three business days. Never send production credentials, access tokens,
personal data, customer records, raw prompts, or destructive proof-of-concept
payloads. Revoke any credential accidentally exposed.

See [security/SECURITY.md](security/SECURITY.md) for supported versions,
response timelines, coordinated disclosure, safe-testing boundaries, and
release security controls.
